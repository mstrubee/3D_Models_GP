# 3D_Models_GP

Kit "Modelos 3D Autoplanet": convierte la planta (DXF o PDF), las elevaciones y el plano eléctrico de una tienda en un visor 3D de un solo archivo HTML, y arma fotomontajes sobre la foto del lugar.

- Empezar: `bash instalar.sh`. Guía completa: [LEEME.md](LEEME.md). Reglas de trabajo: [instrucciones_del_proyecto.md](instrucciones_del_proyecto.md). Valores y preguntas abiertas: [parametros_del_proyecto.md](parametros_del_proyecto.md).
- Carpetas: `scripts/` (extractores, generador del visor, fotomontaje), `biblioteca/` (componentes), `datos/` (letreros, cenefa y luces base), `ejemplo_talca/`, `ejemplo_chillan/`, `ejemplo_santarosa/`.
